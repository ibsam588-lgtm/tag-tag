# Google Play Data Safety Draft

Current prototype behavior:

- No account sign-in.
- No ads.
- No analytics SDK.
- No cloud saves.
- No multiplayer server.
- No personal information is collected by the app.
- The idea form stores text locally on the device with browser or WebView local storage.

Suggested Play Console answers for the current build:

- Data collected: No.
- Data shared: No.
- Security practices: No data is collected or shared.
- Delete data: Users can clear app storage from Android settings.

Update this file before release if ads, analytics, accounts, online multiplayer, leaderboards, crash reporting, or cloud saves are added.
